Atividade Banco de Dados 1

Este ficheiro gaurda as imagens do Diagrama de relacionamento de um sistema de uma concessionária de veículos.
Neste diagrama estão representadas as entidades: funcionário, cliente, carro e vendas. 
O sitema tem como objetivo digitalizar os processos da locadora, gerar relatórios precisos e fornecer dados para gestão do negócio.
